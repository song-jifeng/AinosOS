# Ainos OS - AI KILL 智能进程管理器深度实现方案

> 版本: 2.0.0 | 更新: 2026-08-01

## 概述

AI KILL 是 Ainos OS 的智能进程管理器，比传统 OOM killer 更精准。通过多维度评分、行为趋势分析和渐变恢复策略，在系统资源紧张时做出最优的杀进程决策。

## 评分维度

| 维度 | 权重 | 说明 | 计算方法 |
|------|------|------|---------|
| CPU | 20 | CPU 使用率 | 最近 CPU 时间 / 墙钟时间 |
| MEM | 25 | 内存占用 | RSS 绝对值 + 相对系统内存比例 |
| IO | 15 | IO 操作 | 读写字节数分级 |
| NET | 10 | 网络活动 | 文件描述符数 (近似) |
| AGE | 10 | 进程年龄 | 越年轻分数越高 |
| CRITICALITY | 20 | 系统关键性 (负权重) | 关键进程(init/systemd等)分数高 → 总分低 |
| LEAK | 20 | 内存泄漏趋势 | RSS 3 个样本持续增长 |

**总分公式**: `max(0, Σ(weight_i × dim_i) / Σ(weight_i))`，范围 0-100

## 渐变动作

| 分数范围 | 动作 | 说明 |
|----------|------|------|
| 0-39 | NONE | 不操作 |
| 40-59 | WARN | 记录警告到内核日志 |
| 60-79 | TERM | 发送 SIGTERM，等待 1 秒后检查是否退出，未退出则 SIGKILL |
| 80-89 | KILL | 直接发送 SIGKILL |
| 90-100 | GROUP | 发送 SIGKILL 到整个进程组 |

## 安全机制

| 机制 | 说明 |
|------|------|
| 白名单 | 通过 `whitelist` 参数配置进程名，匹配的进程不会被杀 |
| init 保护 | PID 1 不会被杀 (可配置) |
| 内核线程保护 | `PF_KTHREAD` 标记的线程不会被杀 (可配置) |
| 速率限制 | 默认每 10 秒最多执行一次 SIGKILL |
| 每扫描最大杀戮 | 每次扫描最多杀 3 个进程 |

## 配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `scan_interval_ms` | 3000 | 进程扫描间隔 (ms) |
| `threshold_warn` | 40 | 警告阈值 |
| `threshold_term` | 60 | SIGTERM 阈值 |
| `threshold_kill` | 80 | SIGKILL 阈值 |
| `max_kills_per_scan` | 3 | 每次扫描最多杀进程数 |
| `rate_limit_ms` | 10000 | 杀进程速率限制 (ms) |
| `protect_init` | true | 保护 init 进程 |
| `protect_kthreads` | true | 保护内核线程 |
| `whitelist_str` | "" | 白名单进程名 (逗号分隔) |

## 导出 API

| 函数 | 用途 |
|------|------|
| `ai_kill_get_score()` | 获取指定进程的评分 |
| `ai_kill_suggest_victim()` | 建议最佳杀进程候选 |
| `ai_kill_execute()` | 执行杀进程 |
| `ai_kill_whitelist_add()` | 注册白名单进程 |
| `ai_kill_get_config()` | 获取配置 |
| `ai_kill_set_config()` | 设置配置 |

## 编译和使用

```bash
# 编译
cd kernel/ai-kill
make

# 加载
sudo insmod ai_kill.ko

# 查看进程评分
cat /proc/ai-kill/scores

# 查看配置
cat /proc/ai-kill/config

# 修改配置
echo "weight mem 30" > /proc/ai-kill/config
echo "threshold 30 50 70" > /proc/ai-kill/config

# 查看统计
cat /proc/ai-kill/stats

# 查看杀戮历史
cat /proc/ai-kill/history

# 查看行为跟踪
cat /proc/ai-kill/behavior

# 卸载
sudo rmmod ai_kill
```

## 未来扩展

1. **AI 集成**: 通过 ai-daemon 分析进程行为模式，动态调整权重
2. **cgroup 感知**: 结合 cgroup 做更精细的资源控制和进程隔离
3. **进程画像**: 基于历史数据建立进程正常行为基线
4. **预测性杀进程**: 在 OOM 发生前就预测并杀进程
5. **集成自愈模块**: 杀进程后通知 self-heal 验证系统健康
