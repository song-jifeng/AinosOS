# Ainos OS - AI tmpfs 智能文件系统深度实现方案

> 版本: 2.0.0 | 更新: 2026-08-01

## 概述

AI tmpfs 是 Ainos OS 的智能临时文件系统，是一个可挂载的 VFS 文件系统。通过 AI 驱动的访问模式分析，自动将文件分为热/温/冷三级，智能管理内存缓存，在内存压力时优先驱逐冷数据。

## 核心功能

### 1. VFS 文件系统

- 通过 `register_filesystem` 注册，使用 `mount -t ai_tmpfs` 挂载
- 支持 `create`、`unlink`、`mkdir`、`rmdir`、`lookup` 等标准 VFS 操作
- 文件数据使用 kmalloc/krealloc 缓冲区管理
- 支持标准 POSIX 文件操作 (open/read/write/llseek)

### 2. 三级分类

| 分类 | 条件 | 驱逐策略 | 默认保留 |
|------|------|---------|---------|
| HOT | 访问 ≥5 次 且 频率 ≥10/min | 最后驱逐 | 优先保留 |
| WARM | 访问 ≥2 次 | 次优先 | 适度保留 |
| COLD | 其他 | 优先驱逐 | 可被驱逐 |

### 3. 访问跟踪

- 每个文件独立跟踪访问次数、频率、时间戳
- 原子计数器确保并发安全
- 每次访问后自动重新分类

### 4. 内存压力响应

- 三级 LRU 列表管理
- 冷数据驱逐：从 COLD LRU 头部开始
- 跳过正在使用的文件 (`i_count > 1`)
- 跳过最近访问的文件 (1分钟内)

## 编译和使用

```bash
# 编译
cd kernel/ai-tmpfs
make

# 加载
sudo insmod ai_tmpfs.ko

# 挂载
sudo mount -t ai_tmpfs none /mnt/ai-tmpfs

# 使用
echo "test data" > /mnt/ai-tmpfs/test.txt
cat /mnt/ai-tmpfs/test.txt

# 查看状态
cat /proc/ai-tmpfs/status
cat /proc/ai-tmpfs/files
cat /proc/ai-tmpfs/config

# 修改配置
echo "hot_access_min 3" > /proc/ai-tmpfs/config

# 卸载
sudo umount /mnt/ai-tmpfs
sudo rmmod ai_tmpfs
```

## 配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `max_files` | 4096 | 最大文件数 |
| `max_file_size` | 16MB | 最大文件大小 |
| `hot_access_min` | 5 | 热数据最小访问次数 |
| `hot_freq_min` | 10 | 热数据每分钟最小访问频率 |
| `clean_interval` | 30 | 冷数据清理间隔 (秒) |

## 模块参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `hot_access_min` | 5 | 热数据最小访问次数 |
| `hot_freq_min` | 10 | 热数据每分钟最小访问频率 |
| `max_file_size` | 16MB | 最大文件大小 (bytes) |
| `max_files` | 4096 | 最大文件数 |
| `clean_interval` | 30 | 冷数据清理间隔 (秒) |

## 未来扩展

1. **Shrinker 集成**: 注册内核 shrinker，在系统内存压力时自动驱逐冷数据
2. **压缩**: 冷数据自动压缩存储
3. **AI 预测**: 基于访问历史预测下次访问时间，优化缓存策略
4. **跨挂载点统计**: 支持多个挂载点的统一管理
5. **自愈集成**: 内存压力大时通知 self-heal 模块
