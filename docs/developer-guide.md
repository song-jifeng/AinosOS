# Ainos OS 开发者指南

欢迎来到 Ainos OS 开发者指南！本文档将帮助您了解 Ainos OS 的架构，并指导您如何使用 SDK 开发原生应用、扩展桌面环境以及集成 AI 工具。

## 1. 系统架构概览

Ainos OS 是一个以 AI 为核心的现代操作系统，其用户空间架构分为以下几个核心层：

- **Wayland Compositor (`ainos-desktop`)**: 基于 `wlroots` 构建的显示服务器，负责窗口管理、输入处理和图形渲染。
- **桌面环境组件 (`ainos-panel`)**: 基于 GTK3 构建的系统面板，提供应用启动、系统状态和 AI 快捷入口。
- **Ainos SDK (`libainos`)**: 提供统一的 C API，允许应用程序无缝调用本地 AI 模型进行推理、代码生成和数据分析。
- **AI 工具链 (`ai-tools`)**: 包含命令行工具和守护进程，用于模型管理、代码生成和系统级 AI 任务调度。
