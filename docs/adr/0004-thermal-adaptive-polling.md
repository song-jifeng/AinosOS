# ADR-0004: 温控策略使用自适应轮询 + 事件驱动混合模式

## 状态
Proposed

## 日期
2026-08-02

## 背景
当前温控策略每 2 秒固定轮询 CPU 温度。
在温度稳定时浪费 CPU，在温度快速变化时响应不够及时。

## 决策
- 使用自适应轮询间隔：温度稳定时降低采样频率，温度变化剧烈时提高采样频率
- 在 Linux 上通过 `/sys/devices/system/cpu/cpu*/thermal_throttle/` 的 `poll` 监听事件
- 在 Windows 上通过 WMI 事件通知 `SELECT * FROM Win32_TemperatureProbe` 实现事件驱动
- 轮询间隔动态调整：稳定时 5-10s，变化时 0.5-1s

## 影响
- 正面：减少 CPU 占用（温度稳定时降低 80% 轮询开销）
- 正面：温度剧变时响应更快
- 负面：实现复杂度增加
- 负面：Windows WMI 事件驱动在部分硬件上不可靠

## 性能预期
| 场景 | 旧方案 | 新方案 |
|------|--------|--------|
| 空闲（温度稳定） | 每 2s 轮询 | 每 10s 轮询 |
| 负载变化 | 每 2s 轮询 | 事件驱动 <100ms 响应 |
| 持续高负载 | 每 2s 轮询 | 每 1s 轮询 |
