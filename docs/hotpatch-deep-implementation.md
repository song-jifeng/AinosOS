# Ainos OS - Hotpatch 热补丁生成器深度实现方案

> 版本: 2.0.0 | 更新: 2026-08-01

## 概述

Hotpatch 是 Ainos OS 的内核热补丁引擎，支持函数级补丁注册、应用和回滚，通过 kprobe 监控内核函数行为，使用 stop_machine 安全地修改运行中的代码。

## 架构

```
┌──────────────────────────────────────────────────────────────────┐
│                    Hotpatch 热补丁引擎                              │
├──────────────────────────────────────────────────────────────────┤
│                                                                   │
│   ┌──────────────────────────────────────────────────────────┐   │
│   │              补丁管理器                                    │   │
│   │  register() → 注册补丁                                   │   │
│   │  apply() → 应用补丁 (stop_machine)                       │   │
│   │  rollback() → 回滚补丁 (stop_machine)                    │   │
│   │  get_info() → 查询补丁信息                                │   │
```

## 修补原理 (x86_64)

```
原始函数:                           修补后:
┌──────────────────────┐           ┌──────────────────────┐
│ 55            push rbp│          │ E9 xx xx xx xx  JMP │─────→ 补丁函数
│ 48 89 E5      mov rbp,rsp       │ ...                  │
│ ...                          │ ...                  │
└──────────────────────┘           └──────────────────────┘

JMP rel32 编码:
  E9 <offset>  (5 字节)
  offset = target - (source + 5)
```

## 导出 API

| 函数 | 用途 |
|------|------|
| `hotpatch_register()` | 注册补丁 |
| `hotpatch_apply()` | 应用补丁 |
| `hotpatch_rollback()` | 回滚补丁 |
| `hotpatch_register_hook()` | 注册监控钩子 |
| `hotpatch_unregister_hook()` | 取消注册钩子 |
| `hotpatch_get_info()` | 查询补丁信息 |
| `hotpatch_get_stats()` | 获取统计 |
| `hotpatch_autogen()` | 自动生成补丁 (框架) |

## 安全机制

| 机制 | 说明 |
|------|------|
| stop_machine | 修补时停止所有 CPU，防止并发执行 |
| 指令备份 | 应用前保存原始指令，回滚时恢复 |
| 地址检查 | 目标函数必须在内核文本段 |
| 安全检查 | 函数地址有效、非空、非自身 |
| 状态跟踪 | 每个补丁有完整状态机 (registered/applied/rolledback/failed) |
