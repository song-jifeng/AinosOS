# Ainos OS - AI 文件系统 (ai-fs) 架构设计

## 1. 概述

ai-fs 是一个基于 FUSE 的虚拟文件系统，让用户可以通过**语义内容**搜索和管理文件，而不是仅靠文件名。

```
用户: "找上周我编辑的那个关于架构的PPT"
                         ↓
              ┌─────────────────────┐
              │   ai-fs 虚拟文件系统  │
              │   /mnt/ai-fs/       │
              └─────────┬───────────┘
                        │
          ┌─────────────┼─────────────┐
          ▼             ▼             ▼
   ┌──────────┐  ┌──────────┐  ┌──────────┐
   │ FUSE挂载  │  │ 语义索引  │  │ 实时监控  │
   │ (用户态)  │  │ (嵌入向量)│  │ (inotify)│
   └──────────┘  └──────────┘  └──────────┘
```

## 2. 核心功能

### 2.1 语义搜索目录
```
/mnt/ai-fs/search/by-content/    ← 按内容搜索
/mnt/ai-fs/search/by-date/       ← 按时间/语义搜索
/mnt/ai-fs/search/by-type/       ← 按文件类型智能分类
/mnt/ai-fs/search/natural/       ← 自然语言查询接口
```

### 2.2 虚拟目录结构
```
/mnt/ai-fs/
├── search/                      ← 语义搜索入口
│   ├── by-content/              ← 按内容语义搜索
│   │   └── <query>/             ← 输入查询自动生成目录
│   │       ├── result_1.pptx    ← 按相关度排序的结果
│   │       └── result_2.docx
│   ├── by-date/                 ← 按时间语义搜索
│   │   └── "上周"/"最近"/"昨天"/
│   └── natural/                 ← 自然语言查询
│       └── "找架构相关的PPT"/
│
├── tags/                        ← 按AI自动标签组织
│   ├── work/
│   ├── personal/
│   └── project-ainos/
│
├── smart/                       ← 智能文件夹
│   ├── recent-ai-files/         ← 最近AI相关文件
│   ├── large-files/             ← 大文件
│   └── duplicates/              ← 重复文件检测
│
└── .ainos/                      ← ai-fs 元数据
    ├── index/                   ← 向量索引存储
    ├── config                   ← 索引配置
    └── stats                    ← 索引统计
```

## 4. 索引流程

```
文件系统变更 (inotify)
       │
       ▼
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  文件变更检测  │────▶│  文本内容提取  │────▶│ 嵌入向量生成  │
│  (create/    │     │  (pdf/docx/  │     │  (调用AI嵌入  │
│   modify)    │     │   txt/图片)  │     │   模型)       │
└──────────────┘     └──────────────┘     └──────┬───────┘
                                                  │
                                                  ▼
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  语义搜索查询  │◀────│  向量数据库    │◀────│  向量存储     │
│  (自然语言)   │     │  (HNSW索引)  │     │  (FAISS)     │
│  → 嵌入向量   │     │  相似度排序   │     │              │
└──────────────┘     └──────────────┘     └──────────────┘
```

## 5. 嵌入模型选择

| 用途 | 推荐模型 | 向量维度 | 大小 | 离线 |
|------|---------|---------|------|------|
| 通用文本嵌入 | Nomic Embed Text | 768 | ~80MB | ✓ |
| 代码嵌入 | starcoder2-3b | 2048 | ~1.5GB | ✓ |
| 多模态 | CLIP | 512 | ~600MB | ✗ |
| 中文优化 | BGE-large-zh | 1024 | ~1.2GB | ✓ |

## 6. 关键接口

```c

int ainos_fs_search(const char *query,                    // 语义搜索

                     int max_results);

                       char **tags, int *count);

                       char *category, size_t max_len);
```

## 7. FUSE 实现策略

```c
// FUSE 操作回调 (低级别API)
static struct fuse_lowlevel_ops ai_fs_ops = {
    .lookup    = ai_fs_lookup,     // 路径查找 → 触发语义搜索
    .getattr   = ai_fs_getattr,    // 属性获取
    .readdir   = ai_fs_readdir,    // 目录读取 → 返回搜索结果
    .open      = ai_fs_open,       // 打开文件
    .read      = ai_fs_read,       // 读取文件内容
    .readlink  = ai_fs_readlink,   // 符号链接 → 指向真实文件
};
```

## 8. 性能优化

- **增量索引**: 只索引变更的文件，通过 inotify 监控
- **索引缓存**: LRU 缓存最近查询的嵌入向量
- **并行索引**: 多线程并行处理文件索引
- **预加载**: 根据用户行为预测可能的查询，预加载索引
- **分级存储**: 热索引在内存，冷索引在磁盘
